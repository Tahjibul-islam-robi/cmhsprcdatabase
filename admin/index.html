Import & backup

Move the current JSON records in, or keep a private encrypted copy.

⇧

Import student JSON

Select the existing students.json file. The preview checks IDs and fields before anything is saved.

Existing student values are kept; the import fills only blank fields. Club status and area-of-interest fields are not imported.

⇩

Encrypted backup

Download a passphrase-protected backup of student and attendance data to your own device.

Restore merges records by ID. It does not erase records absent from the backup. Keep the passphrase somewhere safe.

⌑

Free plan reminder

Supabase Free may pause a project after a week without activity and does not provide automatic database backups. Download encrypted backups regularly and keep the file outside GitHub.
